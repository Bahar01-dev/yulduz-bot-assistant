# Идея: ИИ-Агент для ведения Instagram-блога

**Ниша блога:** AI-инструменты, боты, автоматизация — для коучей, психологов, онлайн-школ  
**Цель блога:** Привлечь клиентов на разработку сайтов и ботов

---

## 1. ЧТО ДЕЛАЕТ

- Пишет посты для Instagram (текст + хэштеги + эмодзи + призыв к действию)
- Создаёт контент-план (период и формат задаёт пользователь в момент запроса)
- Пишет сценарии Reels (текст + описание визуала + монтаж + музыка)
- Ищет актуальные темы и тренды в интернете по нише
- Предлагает варианты ответов подписчикам (функция активируется после загрузки базы частых вопросов)

---

## 2. ДЛЯ КОГО

Работает только для одного пользователя — владельца блога.  
Доступ сторонним лицам не предусмотрен.

---

## 3. ОТКУДА БЕРЁТ ИНФОРМАЦИЮ

- Самостоятельно ищет актуальные тренды и темы в интернете
- Опирается на заданную нишу: AI-инструменты, боты, автоматизация для коучей, психологов, онлайн-школ
- Стартует с нуля — без архива контента
- В будущем: пользователь загрузит базу частых вопросов от подписчиков для функции ответов

---

## 4. ГДЕ ЖИВЁТ

Telegram-бот. Пользователь общается с агентом через чат в Telegram.

---

## 5. ЧТО ВЫДАЁТ

| Функция | Формат вывода |
|---|---|
| Пост | Текст + хэштеги + эмодзи + призыв к действию |
| Контент-план | Таблица или список — формат и период задаёт пользователь |
| Сценарий Reels | Текст (что говорить) + описание визуала + монтаж + музыка |
| Ответы подписчикам | Варианты ответов на вопросы (после загрузки базы) |

---

## Заметки для спецификации

- Агент должен уметь искать в интернете (web search)
- Контент-план гибкий: пользователь сам указывает период и формат при запросе
- Функция ответов подписчикам — отложенная, включается после появления данных
- Платформа: Telegram Bot API
