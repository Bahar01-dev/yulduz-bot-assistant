# Yulduz Bot Assistant

**Персональный ИИ-агент для ведения Instagram-блога, живущий в Telegram: пишет посты и сценарии Reels в вашем стиле, собирает контент-план и приносит утренний бриф по трендам ниши.**

Ниша блога — AI-инструменты, боты и автоматизация для коучей, психологов и онлайн-школ. Бот односользовательский по замыслу: он обслуживает только владельца, поэтому публичного демо нет — репозиторий открыт как пример кода, а не как сервис.

---

## Чем отличается от «пересылки промпта в Claude»

Обычный чат с моделью не знает, как вы пишете, и каждый раз начинает с чистого листа. Здесь под диалогом лежит слой памяти и стиля:

| Механика | Что делает |
|---|---|
| **Онбординг стиля** | 5 вопросов в FSM-диалоге → профиль бренда (ниша, аудитория, тон, референсы) в БД |
| **Выбор хука** | Бот даёт 3 варианта захода, вы выбираете — и только потом пишется полный текст |
| **Обучение на фидбеке** | Кнопки 👍 / 👎 под результатом копятся в `style_feedback` и подмешиваются в следующий промпт |
| **Память публикаций** | Уже вышедшие темы не предлагаются повторно |
| **Голосовой ввод** | Надиктовали идею голосом → Groq Whisper расшифровывает → уходит в тот же поток |
| **Утренний бриф** | APScheduler в вашем часовом поясе приносит тренды ниши через веб-поиск Tavily |

Методика («как писать») задана промпт-инжинирингом в [`prompts/`](prompts/) — стиль собирается динамически из профиля, истории и фидбека в [`prompts/style_builder.py`](prompts/style_builder.py).

## Что умеет

| Команда / действие | Результат |
|---|---|
| Свободный текст | Оркестратор определяет намерение и запускает нужный поток |
| Пост для Instagram | 3 хука → выбор → полный текст + хэштеги + CTA + чеклист |
| Сценарий Reels | 3 хука → выбор → побитовый сценарий с таймингами, визуалом и подписью |
| `/план` | Контент-план на неделю или месяц |
| `/тренды` | Актуальные темы ниши через веб-поиск |
| `/menu` | Черновики, профиль, переключение тона |
| Голосовое сообщение | Расшифровка и запуск потока поста или Reels |

## Стек

| Слой | Технология |
|---|---|
| Бот | aiogram 3.29 (long polling, FSM, роутеры, middleware) |
| Язык | Python 3.12, async/await |
| LLM | `anthropic` SDK напрямую **или** `openai` SDK к OpenAI-совместимому шлюзу (OpenRouter) |
| Речь → текст | Groq Whisper (опционально) |
| Веб-поиск | Tavily (опционально) |
| БД | SQLite через `aiosqlite`, 5 таблиц |
| Расписание | APScheduler с IANA-поясом |
| Тесты | pytest + pytest-asyncio — 38 тестов |
| Деплой | Docker → Railway (Persistent Volume под БД) |

## Архитектура

```
Telegram
  │
  ▼
OwnerMiddleware ── чужой user_id → отказ, дальше апдейт не идёт
  │
  ▼
handlers/  (aiogram-роутеры, порядок регистрации важен)
  start → message → callbacks → menu → plan → trends → voice
  │
  ▼
agents/orchestrator.py — detect_intent + extract_topic
  ├─ post_writer     → пост (3 хука → полный текст)
  ├─ reel_writer     → сценарий Reels
  ├─ planner         → контент-план
  ├─ trend_analyst   → бриф по трендам (Tavily)
  └─ onboarding      → профиль бренда
  │
  ▼
prompts/style_builder.py — сборка системного промпта
  (профиль бренда + прошлые публикации + фидбек 👍/👎)
  │
  ▼
utils/errors.safe_generate — retry + backoff + маппинг ошибок в RU-сообщения
  │
  ▼
LLM: Anthropic напрямую | OpenRouter (одна переменная окружения)
  │
  ▼
SQLite: brand_profile · publications · drafts · style_feedback · trend_brief
```

## Решения, на которые стоит посмотреть в коде

**Один слой ошибок вместо `try/except` по всему проекту.** В [`utils/errors.py`](utils/errors.py) лежит `ERROR_CATALOG`: таблица «ситуация → русское сообщение пользователю + уровень лога + слать ли алерт владельцу + сколько раз повторять». `safe_generate` делает экспоненциальный backoff (≈1с, 2с) только для ситуаций, где повтор осмыслен — сеть, 5xx, таймаут, пустой ответ — и не ретраит `RateLimit`, `Auth`, `BadRequest` и контент-фильтр, где повтор лишь потратит квоту. Сверху в [`main.py`](main.py) висит глобальный `@dp.errors()`: любое необработанное исключение превращается в понятное сообщение пользователю, traceback в логи и алерт владельцу — бот не падает.

**Смена LLM-провайдера — одна переменная.** Пусто в `LLM_BASE_URL` → прямой `AsyncAnthropic`. Задано → `AsyncOpenAI` с этим `base_url`, то есть OpenRouter и любой совместимый шлюз. Код агентов при этом не меняется.

**Гейт владельца — middleware, а не проверка в хэндлерах.** [`OwnerMiddleware`](handlers/__init__.py) отсекает чужие апдейты до того, как они дойдут до логики. Проверку нельзя забыть добавить в новый хэндлер — она структурно выше всех.

**Деградация вместо отказа.** Нет `GROQ_API_KEY` — голосовой роутер просто не регистрируется. Нет `TAVILY_API_KEY` — не стартует планировщик и раздел трендов. Бот поднимается на двух обязательных ключах.

## Структура

```
main.py            # точка входа: Bot, Dispatcher, роутеры, error-handler, планировщик
config.py          # переменные окружения с валидацией и понятными RU-ошибками
agents/            # оркестратор намерений + генераторы (пост, Reels, план, тренды, онбординг)
handlers/          # aiogram-роутеры + OwnerMiddleware
prompts/           # сборка системного промпта и методика письма
database/          # aiosqlite-слой: профиль, публикации, черновики, фидбек, брифы
utils/             # errors (каталог + retry), formatter, keyboards, scheduler, state, logger
tests/             # 38 тестов: БД-слой, промпты, гейт владельца, роутинг
```

## Локальный запуск

```bash
git clone https://github.com/Bahar01-dev/yulduz-bot-assistant.git
cd yulduz-bot-assistant
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env    # заполнить своими значениями
python main.py
```

Таблицы SQLite создаются автоматически при старте (`init_db`, idempotent).

### Переменные окружения

Все ключи с пояснениями — в [`.env.example`](.env.example). Обязательные:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `OWNER_TELEGRAM_ID` | Ваш Telegram user ID — бот работает только для него |
| `ANTHROPIC_API_KEY` | Ключ выбранного LLM-провайдера (Anthropic или OpenRouter) |

Опциональные: `LLM_BASE_URL`, `LLM_MODEL`, `GROQ_API_KEY` (голос), `TAVILY_API_KEY` (тренды), `TREND_DIGEST_TIME`, `TREND_TZ`, `DATABASE_PATH`.

> `.env` в `.gitignore` и никогда не попадал в историю репозитория. В `.env.example` только плейсхолдеры.

### Docker

```bash
docker build -t yulduz-bot .
docker run --env-file .env -v $(pwd)/data:/app/data yulduz-bot
```

На Railway каталог `/app/data` монтируется как Persistent Volume, иначе база потеряется при редеплое.

### Тесты

```bash
pytest
```
